The basic commands from the book's exercise:

| Command | Does |
|---|---|
| `pwd` | shows where you are |
| `cd` | goes back to your home directory |
| `cd /tmp` | goes to /tmp |
| `mkdir files` | creates a directory |
| `touch file1` | creates an empty file |
